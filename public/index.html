About

MediSearch is a file-backed searchable patient record system built for a DSA-III project. It allows medical professionals to perform simultaneous multi-keyword searches across all patient files.

Core Specifications

Core Algorithm
Aho-Corasick (Trie construction, BFS failure links, 32-bit output bitmask).
Storage
Local Java File Handling (data/patients/*.txt, data/users/users.txt). No database is used.
Language & Backend
Java (Standard Library com.sun.net.httpserver.HttpServer).
Frontend
Plain HTML5, CSS3, Vanilla JavaScript.

Aho-Corasick Implementation Details

  • Trie Transition Matrix g[][]: Stores prefix tree edges.
  • Failure Links f[]: Computed level-by-level using Queue BFS. Enables scan without backtracking.
  • Output Bitmask out[]: Bit i indicates keyword i match.
  • Bitmask Constraint: Supports up to 32 keywords per search due to 32-bit integer bitwise operations.
  • Time Complexity: O(M + N + Z) where M = total keyword length, N = text length, Z = total matches.
